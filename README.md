# চাকরিবন্ধু (ChakriBondhu) – job-seeker survey

Free Bangla survey page. No payment.

Answers go to a Google Sheet:
1. Create a Google Sheet → Extensions → Apps Script → paste `google-apps-script.gs` → save.
2. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Copy the URL.
3. Paste it into `FORM_ENDPOINT` near the bottom of `index.html`.
